# The House of Platera: 3D experience plan

Approved by the client on 2026-10-05. Supersedes the brief's "Phase 1 has no WebGL":
the client wants the 3D world to be the site. The commerce engine (pricing, checkout,
payments, stock, admin) stays underneath, unchanged.

## Decisions
- Palette: Emerald Vault (velvet #0B2420, ivory, silver, antique gold, ruby for bridal).
- Entrance piece: an original Platera emblem built in code (not a product).
- The 27 pieces: cut-out photographs relit live by a moving lamp (pieceLight shader),
  upgradeable to true 3D models per piece later.
- Phones: the full walk-through, with adaptive quality tiers (high / mid / low).

## Architecture
- One persistent `<Canvas>` behind every shop page (components/world/World.tsx).
- Pages declare a station with `<WorldStation>`: home, room, lamp, quiet.
- Page sections marked `data-world-section="N"` drive the camera (scroll 0 → N).
- All text, prices and actions stay server-rendered HTML on top: crawlable, accessible,
  and a complete shop without WebGL.
- Colours come from CSS tokens at runtime (palette.ts); no hex in 3D code.

## Core (first)
1. World canvas, tiers, studio environment, camera rig, pointer → light.
2. Home: entrance with emblem → corridor → one alcove per collection → counter.
3. Collection rooms: every piece on one long tray; scroll slides along; click to open.
4. The Lamp (product page): piece on a tilted pad; the visitor moves the light.
5. Page transition: a sheen of light wipes across between pages.

## Approved sections (then, in this order)
1. **The Weighing** (product page): brass balance settles on the real weight; the price builds line by line.
2. **Light Moods** (product page): Daylight · Diya · Evening · Mandap relight the piece.
3. **On the Neck** (necklaces): marble bust with 16/18/20/24 in length rings; piece at true length.
4. **The Hallmark Strike** (home and /hallmark): a punch strikes 925 + HUID into silver.
5. **The Stone Room** (home and CZ pieces): a giant brilliant you turn; honest CZ explanation.
6. **The Vault Drawer**: saved pieces in a 3D drawer; share on WhatsApp.
7. **The Gift Box** (order confirmation): box closes, ribbon ties.
8. **Festival Rooms**: owner switches Diwali / wedding-season lighting from admin.

## Quality floor (unchanged from the brief)
DPR cap 2 (1.5 phones), render pauses when hidden, dispose on unmount, reduced-motion
gives one posed frame, no WebGL gives the HTML shop, test at 390×844 with 4× CPU throttle.
